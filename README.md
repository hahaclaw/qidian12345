# 启动点12345 多空信号

GitHub Actions 定时扫描国内商品期货**全部主力连续合约**，出现启动点信号时推送到企业微信群。

## 原理

```
GitHub Actions 定时(cron) → akshare 并发拉新浪期货K线 → 判断最新已收盘K线
→ 有信号则按多/空分组推送到企业微信 → 已推送记录写入 state.json 提交回仓库，防止重复
```

## 文件

| 文件 | 作用 |
|---|---|
| `scan.py` | 扫描主程序（**文件名不能改成 `signal.py`**，会与 Python 标准库冲突导致崩溃） |
| `requirements.txt` | Python 依赖 |
| `state.json` | 去重状态，每次运行后自动提交 |
| `.github/workflows/signal.yml` | 定时任务 |

## 覆盖范围

标的不写死，每次运行从新浪动态获取**全部主力连续合约**（`XX0` 即主力连续，代表该品种的主力合约，不是单个交割月份），并补入新浪列表遗漏的 `TL0`（30年国债）、`T0`（10年国债），实测 **84 个**。接口异常时使用内置的六大交易所回退表。

### 只算主力品种，自动剔除不活跃的

以下品种会被整品种跳过（所有周期都不计算）：

| 条件 | 说明 |
|---|---|
| 5 日成交量中位数 < `MIN_VOL`（默认 10000 手） | 成交太清淡，信号无参考价值 |
| 最新持仓量 < `MIN_OI`（默认 10000 手） | 持仓太少，流动性风险大 |
| 最后一根 K 线超过 10 天 | 已停牌 |
| K 线不足 125 根 | 数据不够算 MA120 |

实测剔除 11 个：粳稻、早籼稻、强麦、晚籼稻（已停牌）、纤维板、原木、粳米、菜籽、胶版印刷纸、铂、钯。

最终计算 **73 个活跃品种**。门槛可在仓库 Variables 里用 `MIN_VOL` / `MIN_OI` 调整。

## 推送格式（可交易合约在前）

每条信号**开头就是当前可交易的主力合约**，加粗显示，后面跟交易所、周期、收盘价，最后附主连代码作参考：

```
↑ 做多 **沪金2612(AU2612)[M]** 上期所 60分钟  收盘 883.22  主连AU0  K线 2026-11-10 09:30:00
↓ 做空 **氧化铝2701(AO2701)[M]** 上期所 15分钟  收盘 2646.0  主连AO0  K线 2026-11-10 09:15:00
```

| 字段 | 含义 |
|---|---|
| `氧化铝2701` | 当前主力合约名称，文华里带红色 <kbd>M</kbd> 标记的那个 |
| `(AO2701)` | 交易所标准合约代码，可直接搜索、下单 |
| `[M]` | 对应文华的 M 标记，表示当前主力 |
| `主连AO0` | 信号计算所用的主连序列（新浪代码），仅作溯源参考 |

主力合约按**持仓量最大**自动识别，覆盖 74 个活跃品种，全部解析成功。换月时自动更新，无需改代码。

识别失败时会明确标 `主力未识别`，不会用主连代码冒充可交易合约。

## 中文名称映射

新浪和文华的中文名不一致的已做映射：`黄金→沪金`、`螺纹钢→螺纹`、`热轧卷板→热卷`、`天然橡胶→橡胶`、`中证指数→中证1000`、`10年期国债→十年国债` 等。

在文华手机版搜索框输入品种名（如 **氧化铝**），结果里会列出「氧化铝主连」「氧化铝加权」和各月份合约，带红色 <kbd>M</kbd> 的就是推送里指的那个主力合约。

## 运行时间（北京时间，周一至周五）

| 时段 | cron | 说明 |
|---|---|---|
| 日盘 | `*/15 1-7 * * 1-5` | 09:00 - 15:45，每 15 分钟 |
| 夜盘 | `*/15 13-18 * * 1-5` | 21:00 - 02:45，每 15 分钟 |

## 配置

在 Settings → Secrets and variables → Actions 添加：

- `WECOM_WEBHOOK` —— 企业微信群机器人的 Webhook 地址

获取方式：企业微信群 → 群机器人 → 添加机器人 → 复制 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`

## 可调参数

`scan.py` 顶部：

```python
PERIODS = ["15", "30", "60", "D"]   # 周期
ZH, ZP, ZF, ZQ = 0.6, 0.4, 0.8, 10  # 粘合/走平/振幅/振幅窗口
EXCLUDE = set()                      # 不想扫的品种，例如 {"WR0", "BB0"}
WORKERS = 8                          # 并发取数线程数
# MIN_VOL / MIN_OI 默认 10000 手，可用同名环境变量覆盖
```

调整活跃度门槛：在仓库 Settings → Secrets and variables → Actions → **Variables** 里加 `MIN_VOL` 或 `MIN_OI`，workflow 已把它们传进环境，改完下次运行生效。

## 性能

84 标的 × 4 周期 = 336 次取数，8 线程并发。

| 环境 | 取数耗时 | 总耗时 |
|---|---|---|
| 本地 | 15 秒 | 34 秒 |
| GitHub Actions | 约 1～2 分钟 | 约 2 分钟 |

## 已知限制

- **日线只在收盘后判断**：盘中取到的日线是未完成K线，代码会跳过，避免推送假信号。
- **分钟线只看倒数第二根**：没有回看窗口。GitHub 定时任务常延迟 5～30 分钟，若某次触发被跳过，那一根K线的信号可能漏报。
- 推送使用企业微信 markdown 消息，单条上限 4096 字节，超长自动分段发送。
